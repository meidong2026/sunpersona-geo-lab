# Sunpersona 公开 GEO 实验

Sunpersona 是面向中英文品牌的生成式引擎优化服务。这个公开实验使用 Sunpersona 自身作为样本，记录网页访问、品牌识别和官网引用，不代表第三方平台的认证、推荐或效果保证。

## 原始项目入口

- [官网](https://sunpersona.com/)
- [中文介绍](https://sunpersona.com/zh/about/)
- [公开实验室](https://sunpersona.com/zh/lab/)
- [脱敏逐题数据](https://sunpersona.com/lab/results-2026-09-17.json)

## 历史基线

测试日期为 2026-09-17。ChatGPT、Perplexity、Claude、Gemini 各 10 条回答，共 40 条有效样本。Copilot 当时连接失败，不计入分母。

| 观测 | 数量与分母 |
|---|---:|
| 名称出现 | 26/40 |
| 官网引用 | 11/40 |
| 提及后身份准确 | 11/26 |
| 未点名问题出现 | 2/16 |
| 提及中的同名混淆 | 8/26 |

各平台与语言的完整判定保留在公开逐题数据中。模型、登录与联网条件存在差异，不能将此表解释为平台排名或市场覆盖率。

## 方法与边界

每题使用独立会话，不粘贴官网正文。分别测试品牌、域名和未点名问题。公开记录不包含个人账号、密码、验证码、私密会话链接或本地证据路径。

2026-10-09 完成了站内定义、服务说明、双语指南和实验室整改；这些是内容发布记录，不是优化效果。优化后同题复测仍待执行。
